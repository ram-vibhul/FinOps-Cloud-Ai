Getting started

From sign-up to your first savings in a few minutes.

Hosted

  1. Sign up with Google or your company's single sign-on, and create your organisation. You can explore a demo organisation with sample data first.
  2. Connect a cloud account. For AWS, CloudCostRadar gives you a CloudFormation or Terraform template that creates a read-only role; Azure uses a service principal with reader roles, Google Cloud a service account with BigQuery billing export access.
  3. See your first savings. The first import, the cloud's own recommendations and every saving check run straight away; you are notified when the savings are ready.
  4. Invite your team, set a budget, and send alerts to Slack or Microsoft Teams. The guided setup in the app ticks each step off by itself.

In your own environment

You need Docker. The included Compose file runs the web app, the background worker and PostgreSQL 17.

docker compose up -d
docker compose exec web ccradar platform-admin add you@example.com

Without a licence, CloudCostRadar runs its free tier. Install a licence key with ccradar licence install FILE or in the app.

The full installation guide is part of the product documentation.
